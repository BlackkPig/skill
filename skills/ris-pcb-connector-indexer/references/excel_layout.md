# Excel 交付规范

本技能最终交付的 `.xlsx` 必须来自已经通过校验的 mapping JSON/CSV，禁止在 Excel 阶段猜测或补齐映射。

## 工作表 1：`RIS路索引`

建议列：

1. 序号
2. 阵面行
3. 行内列
4. X坐标(mm)
5. Y坐标(mm)
6. 连接器
7. 引脚
8. 引脚前缀
9. 引脚号
10. Via索引
11. 起始层
12. 终止层
13. 状态

标题区写明：

- 排序规则：**阵面正视/Top View，从左到右，再从上到下**。
- 总路数、阵面行列数。
- 唯一性校验结果。
- 若用户提供 anchor，写明 anchor 全部通过。

## 工作表 2：`阵面映射矩阵`

- 行 = 阵面行，列 = 阵面列。
- 单元格内容：`RIS序号` 换行 `连接器引脚`。
- 视觉方向必须与正视图一致：左上角是 RIS 1。
- 冻结首行/首列，单元格居中并自动换行。

## 工作表 3：`连接器反查`

列：连接器、引脚、是否用于RIS、RIS序号、阵面行、阵面列、引脚坐标。

- 应列出目标连接器的全部命名焊盘；未用于 RIS 的引脚也保留。
- 允许用引脚反查 RIS 序号。

## 工作表 4：`说明`

至少记录：

- 输入 PcbDoc 文件名（只写文件名，不公开完整本地路径）。
- 连接器位号。
- 总路数、阵面规模。
- 排序方向。
- 几何追线方法与容差。
- source via span。
- 唯一性、计数、anchor 校验结果。
- 已知限制与人工复核提示。

## 样式

- 专业工程表格风格，标题深蓝，表头中蓝，正文浅色交替行。
- 表头冻结，列宽适中，不让长文本被截断。
- 坐标保留 3–6 位小数。
- 不需要图表；重点是可检索、可反查、可审计。

## ChatGPT / artifact_tool

在提供 `artifact_tool` 的环境中，应遵循宿主的 spreadsheet skill 规范创建 Excel；使用 mapping JSON 批量写入，完成后检查关键范围并扫描公式错误（本表通常不需要公式）。
