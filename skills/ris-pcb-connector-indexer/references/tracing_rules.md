# 追线与编号规则

## 为什么不用截图直接“看线”

截图只用于确认阵面视觉方向、绿色框对应的控制点位置或辅助定义 ROI。真正的连接器索引必须从 `.PcbDoc` 的铜层几何连接关系得到。不能依据肉眼猜线，也不能根据“引脚编号看起来有规律”外推。

## 默认追线规则

1. 解析 `Components6 / Pads6 / Vias6 / Tracks6`。
2. 找到用户指定连接器（默认示例为 `J8`）及其命名焊盘。
3. 在铜层 1–32 上建立 track / via / connector-pad 连通图。
4. 同层 track：当某段端点落到另一段中心线上时视为连接。
5. via：只有 track 端点终止在 via 铜盘范围内时才连接；这是一条保守规则，用来避免“从 via 附近经过”的线被误判为相连。
6. connector pad：只有 track 端点终止在 pad 区域内时才连接。
7. 一个候选控制 via 必须最终只连到一个连接器引脚；0 个为未匹配，>1 个为歧义，不得猜测。
8. 默认优先选择 Top→Bottom (`1:32`) 的 source via；若用户指定总路数，则优先选择数量恰好匹配该总路数的 via span。

## 阵面编号规则

默认且必须保持：

- 观察方向：阵面正视 / Top View。
- 行内：X 从小到大，即从左到右。
- 行间：Y 从大到小，即从上到下。
- 所以左上角为 1，右下角为 N。

只有用户明确要求其它方向时才允许改变。

## 必做校验

- 路数 = 用户要求路数（若给出）。
- `rows × cols = 路数`（若三者都给出）。
- 每行列数正确。
- 每路恰好一个连接器引脚。
- 连接器引脚在 RIS 映射中不重复。
- 用户给出的 anchor 全部通过。
- 任一项失败：停止并输出诊断，不得生成“看起来完整”的假表。
